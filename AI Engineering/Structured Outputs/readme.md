# Structured Outputs AI

A beginner-friendly AI application built with:

- Node.js
- Express
- OpenAI API
- Structured Outputs
- JSON Schema
- HTML
- CSS
- JavaScript

## Features

- User enters a programming topic
- AI generates structured information
- JSON Schema controls the response format
- Results are displayed on the webpage

## Setup

npm install

Create a .env file:

OPENAI_API_KEY=your_api_key_here

Run:

npm start

Open:

http://localhost:3000
